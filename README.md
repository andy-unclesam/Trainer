# Der Trainer

Interaktive Trainer aus dem eigenen Unterrichtsmaterial – für Mathematik, Latein und jedes Fach mit festen Verfahren. Vor allem zum selbstständigen Üben: Die Kinder kontrollieren ihren Lösungsweg im eigenen Tempo Schritt für Schritt – Aufbau und Notation, nicht nur das Endergebnis (Vorführer mit den Aufgaben des Arbeitsblatts per Knopf); dazu Zufallsaufgaben in drei Stufen (Blitz). Auch an der Tafel einsetzbar. Ein KI-Assistent in Fobizz schreibt einen kurzen Trainer-Code; der Baukasten im Browser prüft ihn und macht daraus eine eigenständige HTML-Datei. Früher „Mathematiktrainer“ – alter Mathematik-Code läuft unverändert.

**Beitrag:** https://andreas-hemmeter.de/Trainer/

| Pfad | Inhalt |
|---|---|
| `index.html` | der Beitrag mit Anleitung |
| `baukasten/` | der Baukasten: Trainer-Code einfügen, Selbsttest, als Datei speichern (läuft vollständig im Browser) |
| `beispiel/` | Beispiel-Trainer Mathematik (Gleichungen mit Platzhalter, Brüche kürzen) |
| `beispiele/` | weitere Trainer: Rechenstrich, Gleichungs-Blitz, Text-Term-Zerleger, Satzbaukasten, Primfaktorzerlegung, Latein Satzglieder, Latein Deklinationen |
| `bilder/` | Abbildungen zum Beitrag |
| `material/Trainer_Paket.zip` | Instruktionen, Skill `trainer`, drei Wissensdateien, Chatstarter, Bild, Anleitung, Baukasten und zwei Beispiele zum Herunterladen |
